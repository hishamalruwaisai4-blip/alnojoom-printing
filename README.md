# النجوم للطباعة — نظام تسعير الطلبيات

تطبيق ويب تقدّمي (PWA) باللغة العربية لإدارة وتسعير طلبيات مطبعة النجوم. يشمل حساب تكاليف الأوفست والديجيتال والورق والهالك والتشطيب، حفظ سجل الطلبيات، نسخاً احتياطية، وطباعة عروض الأسعار. أزيلت منه صفحات الاشتراكات والباقات والتسجيل التجريبي.

## تشغيله على Windows من الملفات

فك ضغط مجلد المشروع بالكامل، ثم افتح مجلد `alnojoom-printing` وشغّل `start.bat`. يتطلب هذا الأسلوب Python 3؛ لا يحتاج إلى تثبيت حزم أو Node. سيُفتح التطبيق على `http://localhost:8000`. اترك نافذة التشغيل مفتوحة ما دام التطبيق مستخدماً.

## GitHub والخصوصية

خزّن الشفرة في مستودع GitHub **خاص** باسم مثل `alnojoom-printing`. لا ترفع قواعد بيانات العملاء أو ملفات النسخ الاحتياطي أو كلمات المرور/الرموز. مستودع الشفرة خاص، لكن نشر التطبيق على GitHub Pages يجعل صفحة الويب عامة الوصول حتى لو كان المستودع خاصاً. لذلك لا يتم تفعيل GitHub Pages تلقائياً في هذا المشروع. وإذا أُريد استخدامه عبر رابط على عدة أجهزة مع بقاء الموقع خاصاً، فذلك يتطلب استضافة خلف تسجيل دخول أو شبكة داخلية، وليس مجرد مستودع GitHub خاص.

## تخزين الطلبات

تُحفظ الإعدادات والطلبيات داخل تخزين المتصفح على الجهاز الحالي فقط. لا يوجد حساب مستخدم أو خادم أو مزامنة تلقائية بين الأجهزة. انقل البيانات يدوياً عبر زر «نسخة احتياطية» ثم «استيراد نسخة» على الجهاز الآخر، واحتفظ بنسخة آمنة خارج المتصفح.

## طريقة الحساب

يحسب التطبيق توزيع المنتج المستطيل على الفرخ مع إمكان إدخال عدد النسخ على الفرخ يدوياً، أفرخ التشغيل والهالك والتجهيز، الورق، زنكات الأوفست، السحبات أو النقرات الرقمية، التشطيب، المصاريف، هامش الربح، الخصم والضريبة. مثال الطلبية الافتراضي يُظهر مجموع تكلفة 29,700 وسعر بيع 38,610 ريالاً، وهو مثال قابل للتعديل وليس تعرفة مطبعتك. أدخل تكاليفك الحقيقية واختبر الحساب على أعمال منفذة قبل اعتماد الأسعار للعملاء.

## الاختبار

من مجلد المشروع شغّل:

```bash
node test-calc-engine.js
```

ملاحظة: بعض عناصر الاقتراح الهندسي لا تمثل نظام فرض احترافي، ولا تتضمن هوامش الماكينة أو مسكات الورق أو اتجاه الألياف أو قراءة RIP. يلزم ضبط القيم على إعدادات وآلات مطبعتك.
